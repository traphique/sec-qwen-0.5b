# sec-qwen-0.5b

An offensive-security-specialized small language model, distilled on an Apple Silicon Mac — no cloud, no GPUs.

The student (**Qwen2.5-0.5B-Instruct**) was fine-tuned via LoRA on synthetic data generated by a **Qwen2.5-7B-Instruct** teacher (4-bit MLX). Training + inference run entirely on-device via [MLX](https://github.com/ml-explore/mlx).

## Results

| | Base (Qwen2.5-0.5B) | Distilled |
|---|---|---|
| Train loss | — | 2.2 → **0.30** (400 iters) |
| Inference speed (M5) | — | **308 tok/s**, 0.36 GB peak |
| Model size (4-bit) | — | **276 MB** |

The distilled model adopts the teacher's structured, technically oriented response style and focuses on security topics (recon, web exploitation, malware analysis, Active Directory attacks, CTF methodology, etc.). At this dataset scale it transfers style and domain orientation more than deep knowledge — see [Scaling notes](#scaling-notes).

## Pipeline

```
gen_dataset.py   teacher (7B) answers seed prompts        -> data/distill.jsonl
augment.py       teacher paraphrases seeds + answers      -> data/distill_aug.jsonl
train_config.yaml  LoRA r=16 fine-tune of the 0.5B student
fuse + convert   merge adapter, quantize to 4-bit         -> models/
eval.py          side-by-side base vs. fine-tuned output  -> eval_output.txt
```

## Reproduce

```bash
uv venv --python 3.11 .venv
uv pip install "mlx-lm[generate]" datasets

# 1. Generate distillation data with the teacher (~30 min on M5)
python gen_dataset.py && python augment.py

# 2. Split train/valid
python - <<'EOF'
import json, random
random.seed(7)
lines = [l for l in open('data/distill.jsonl')] + [l for l in open('data/distill_aug.jsonl')]
random.shuffle(lines)
n = max(4, len(lines)//10)
open('data/valid.jsonl','w').writelines(lines[:n])
open('data/train.jsonl','w').writelines(lines[n:])
EOF

# 3. LoRA fine-tune (~6 min on M5)
python -m mlx_lm lora --config train_config.yaml

# 4. Merge + quantize
python -m mlx_lm fuse --model mlx-community/Qwen2.5-0.5B-Instruct-bf16 \
    --save-path models/sec-qwen-0.5b --adapter-path adapters
python -m mlx_lm convert --hf-path models/sec-qwen-0.5b -q \
    --mlx-path models/sec-qwen-0.5b-4bit

# 5. Chat with it
python -m mlx_lm chat --model models/sec-qwen-0.5b-4bit
```

## Scaling notes

- 84 samples shifts *style and focus*; 1-2k+ seeds would be needed to transfer real knowledge. Expand the `DOMAINS` dict in `gen_dataset.py`.
- A 1.5B student (e.g. Qwen2.5-1.5B) still fits LoRA fine-tuning in 24 GB unified memory and retains far more fluency.
- An LLM-as-judge pass to filter weak teacher outputs improves quality per sample.
